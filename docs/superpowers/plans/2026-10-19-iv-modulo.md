# Módulo IV: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** acrescentar à plataforma o módulo IV, com estes tipos de atividade:
- questões "qual molécula corresponde ao espectro?" (2 → 5 opções por nível), misturadas com teóricas;
- pool de sala (quiz ao vivo e slides) e pool de casa (nota de prática separada);
- atividade em grupo com 6 problemas diferentes, apresentados e revelados pelo professor.

**Architecture:** uma biblioteca de compostos em Python (`tools/iv/`) é a fonte única. Com RDKit e matplotlib, ela gera:
- `public/conteudo/iv/compostos.json`, com bandas (incluindo as da impressão digital), fórmula e nº de C;
- estruturas PNG lisas (sem destaque);
- espectros PNG, só para os slides.

No site, o espectro é desenhado em SVG a partir das bandas (`core/iv.js`). As alternativas que são estruturas viram o token `@est:<id>`. O site passa a ter **módulo** (`uvvis` | `iv`), escolhido por `?m=` ou no menu.

**Tech Stack:** a mesma do UV-vis (HTML + ES modules, Firebase 10.14.1, `node --test`, `@firebase/rules-unit-testing`). Para gerar conteúdo: Python 3.12 + RDKit 2026.09 + matplotlib + numpy, testados com `python3 -m unittest`. Os slides usam pptxgenjs (de `../Aula_IV/build/node_modules`) + qrcode.

**Spec:** `docs/2026-10-19-iv-modulo-design.md`

## Global Constraints

- Estruturas **só em preto, sem destaque e sem nome** nas questões; nenhuma figura ou título pode entregar a resposta.
- Níveis e nº de opções: **fácil = 2, médio = 3–4, difícil = 5**. No médio e no difícil, as opções têm nº de C dentro de **±1** do composto certo. A fórmula **não** aparece nas questões de espectro; aparece **só nos problemas de grupo**.
- Eixo do espectro: 4000 → 400 cm⁻¹ (invertido), %T com bandas "para baixo", ticks 4000/3000/2000/1500/1000/500. É legível em 360 px de largura.
- Sala: **2 rodadas × 10**, sendo rodada 1 = fácil + médio (+2 teóricas) e rodada 2 = médio + difícil (+2 teóricas). Sequência fixa e slides de pergunta → resposta, com "Por quê?" e "💬 Discuta com o colega".
- Casa: ~80 questões (~60 de espectro e ~20 teóricas), **nenhuma questão idêntica** às de sala (mesmo composto-alvo com o mesmo conjunto de opções). Compostos dos problemas de grupo **nunca** aparecem na sala nem em casa.
- Grupo: **sem pontuação**. A resposta e a resolução ficam em `privado/iv-grupo.json` (gitignored), carregadas pelo professor e lidas só por ele.
- Prática de IV **separada** da de UV-vis no painel e no CSV. O corte de IV é configurável (`CORTE_PRATICA.iv`, inicialmente `null` = "a definir").
- Quinta alternativa: forma **★**, cor **#7B2FBE**, além de ▲ #E21B3C, ◆ #1368CE, ● #D89E00, ■ #26890C.
- Todo texto em português. Nada do UV-vis pode quebrar: a suíte atual (55 + 18 regras) continua verde.
- Toda mudança em `firestore.rules` exige avisar o professor para colar as regras no console.

## Review Focus

1. **Aluno com link antigo do UV-vis (sem `?m=`):** continua caindo no UV-vis, com registro e personagem preservados. Teste em Task 4.
2. **Espectro em celular de 360 px:** as bandas finas (C≡N 2250, C≡C 2120) continuam visíveis, com o traço ≥ 1,5 px e a amostragem fina perto delas. Teste em Task 2 (o mínimo local aparece com 1500 pontos).
3. **Questão de 5 opções no quiz:** o botão ★ existe no celular e no telão e a regra aceita `alternativa` 0–4. Teste em Task 5.
4. **Grupo enviando duas vezes, ou dois celulares do mesmo grupo:** fica a última entrega, sem duplicar, e o professor vê uma só. Teste nas regras e em `core/grupo-iv.js` (Task 6).
5. **Professor revela antes de todos entregarem:** os grupos sem entrega aparecem como "sem entrega", e a revelação não quebra. Teste em Task 6.

## Formato dos dados (usado nas Tasks 1–8)

```jsonc
// compostos.json: { "compostos": { "<id>": {...} } }
{ "id": "2-pentanona", "nome": "2-pentanona", "funcao": "cetona", "familia": "carbonila",
  "formula": "C5H10O", "nC": 5, "insaturacoes": 1,
  "bandas": [[1717, 1.6, 9, "l"], [3330, 1.1, 130, "g"], ...],   // inclui as da impressão digital, já sorteadas
  "diagnostico": "C=O forte em 1715 cm⁻¹ e nenhum O–H ou C–H de aldeído → cetona.",
  "estrutura": "estruturas/2-pentanona.png" }

// questão de espectro (casa e sala)
{ "id": "iv-c-012", "bloco": 3, "tipo": "mc", "subtipo": "espectro", "nivel": "medio",
  "espectro": "2-pentanona", "enunciado": "Qual molécula corresponde a este espectro?",
  "alternativas": ["@est:pentanal", "@est:2-pentanona", "@est:acetato_etila"], "correta": 1,
  "explicacao": "<diagnostico do alvo> As outras: pentanal teria C–H de aldeído (2820/2720); …" }

// teórica: igual às do UV-vis ({tipo:"mc", alternativas de texto}), com "nivel" e "bloco".
// grupo.json (público):  { "problemas": [{ "n": 1, "formula": "C6H12O", "espectro": "<id>", "pista": "…",
//                          "candidatas": ["@est:a", "@est:b", …] }] }   (sem a resposta)
// privado/iv-grupo.json: { "problemas": [{ "n": 1, "correta": 2, "resolucao": "…", "bandasChave": ["1715 C=O", …] }] }
```

  - escolher o grupo 1–6;
  - ver o problema daquele grupo: fórmula, espectro, pista e candidatas como estruturas;
  - montar a equipe (membros), escolher a estrutura e escrever a justificativa ("atribua as bandas: 1715 cm⁻¹ = …"), com o lembrete de insaturações `I = C − H/2 + N/2 + 1`;

- Professor:
  - criar a atividade (sorteia ou mantém 6 dos 8 problemas) e projetar o QR;
  - ver a tabela de grupos (entregue/sem entrega, em tempo real);
  - **Projetar grupo k**: espectro grande, fórmula, estrutura escolhida e justificativa;
